# gamesrebirth/.github

Organization-wide files for Games Rebirth:

- `profile/README.md`: the organization profile page.
- `COPYRIGHT-NOTICE.md`: the copyright, trademark, and takedown policy.
- `.github/ISSUE_TEMPLATE/`: the takedown request form, also the default issue
  template for every repository in the organization that has none of its own.

Takedown requests are filed as issues in this repository.
