# Copyright and Trademark Notice

Games Rebirth is a non-commercial fan community that remakes and preserves
old games, mostly mobile Java (J2ME) and PC games from the 2000s, so they can
be played on today's devices.

## Not affiliated

Games Rebirth is not affiliated with, endorsed by, sponsored by, or connected
to any of the original developers, publishers, or rights holders of the games
it remakes. Game titles, character names, logos, and other trademarks named in
this organization belong to their respective owners. They are used only to
identify the original work that a project is about.

## What our projects aim to do

- Write new code from scratch. Projects do not copy or decompile the original
  game's code.
- Use assets made by contributors, or assets under an open license that allows
  it, with credit.
- Where a project needs the original game data, ask players to supply their own
  legally obtained copy. Repositories do not host or link to original game
  files, ROMs, JARs, or ripped assets.
- Stay non-commercial: no sales, no ads, and no donations tied to a remake.

These are goals, not a guarantee that every file is free of third-party
material. If you find something that should not be here, tell us.

## Takedown requests

If you own the rights to a game, or act on behalf of the owner, and want any
content removed, we will remove it promptly, without argument.

- **Open a takedown request:**
  <https://github.com/gamesrebirth/.github/issues/new?template=takedown-request.yml>.
  Issues are public, so do not include private details you do not want shown.
- **Prefer a private channel?** Use GitHub's own DMCA process:
  <https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy>.

Please name the repository or file, the work you hold rights to, and what you
want removed. Once a request is confirmed, the affected content is taken down
and the request is closed with a note of what was removed.

## Contributors

Do not submit original game code, decompiled code, ripped assets, or game files.
Contributions that include them will be removed.
